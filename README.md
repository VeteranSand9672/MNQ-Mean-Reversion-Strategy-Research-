**MNQ Mean Reversion Strategy Research**

**Asset:** Micro E-mini Nasdaq-100 Futures (MNQ)  
**Research Area:** Intraday Systematic Trading  
**Implementation:** Pine Script v6, Python  
**Analysis:** Trade Performance, Risk, Execution Costs

This project examines an intraday MNQ futures strategy using TradingView backtesting and Python-based trade analysis to evaluate performance, risk, and execution costs.

---

**Strategy Overview**

- Rules-based entry and exit logic
- Configurable risk and position management
- Historical trade data analysis

---

**Performance Metrics**

- Net P&L and win rate
- Profit factor and average trade
- Maximum drawdown and equity curve

---

**Technology**

Python · pandas · Matplotlib · Pine Script v6

---

**Setup**

```bash
pip install -r requirements.txt
python python/analyze_trades.py
```

Requires trade data formatted for the analysis script.

---

**Further Research**

Transaction-cost sensitivity, parameter stability, and out-of-sample testing.

---

*Independent quantitative research project. Historical backtest results do not guarantee future performance.*
